Hexapod VLA Platform

An end-to-end robot learning platform for the XiaoRGEEK hexapod — autonomous line following, PS5 teleop, data collection, and CNN / VLA policy training, all over a lightweight HTTP API.

What it does

Everything you need to build a walking robot brain

From raw data collection to trained policies — the full pipeline runs on a laptop talking to a Jetson-based hexapod over Wi-Fi.

🎮

PS5 Teleop

Drive the hexapod with a DualSense controller via Bluetooth. Left stick moves, right stick rotates, cross button emergency-stops.

〰️

Colour Line Following

Vision-based line follower for red, white, and blue floor lines. Uses cv2.fitLine to align the robot's heading with the line direction — not just the centroid.

🕹️

PS5 Manual Override

While line-following, move any stick to take manual control instantly. Release and the robot resumes autonomous following.

📹

Episode Recording

Record labelled teleop episodes at 10 Hz. Accept or discard each episode with arrow keys or the PS5 controller before saving.

🧠

CNN Policy

Train an image-based CNN policy from collected episodes. Evaluate checkpoints locally and deploy to the robot in real time.

🤗

LeRobot Export

Export any recorded session to Hugging Face's LeRobot dataset format for use with large Vision-Language-Action models.

📡

ROS 1 Integration

Motor controller publishes to /cmd_vel, /state, and /head_scalar — compatible with the hexapod's C++ controller node.

📷

Orbbec RGB+Depth

Serves the Orbbec Astra's colour stream via a ROS topic fallback when V4L2 is unavailable. Depth data exposed for future obstacle avoidance.

🛡️

Safety Features

Motor watchdog stops the robot if commands time out. Auto sit-down on server shutdown. Stand-up sequence runs automatically at startup.

How it works

System Architecture

The laptop talks to a Flask HTTP server on the robot. The server bridges HTTP commands to ROS 1 topics consumed by the hexapod's C++ controller.

┌─────────────────────────────────────────────────────────────────┐ │ LAPTOP (macOS / Linux) │ │ │ │ PS5 DualSense ──► PS5Controller ──┐ │ │ Keyboard ──► TeleopController ──┤ │ │ ├──► RobotClient (HTTP) │ │ LineFollower ──┤ POST /velocity │ │ CNNPolicy ──┘ GET /snapshot │ │ │ └───────────────────────────────┬─────────────────────────────────┘ │ Wi-Fi (HTTP :8080) ┌───────────────────────────────▼─────────────────────────────────┐ │ ROBOT (Jetson TX1 · ROS Melodic) │ │ │ │ Flask HTTP Server │ │ ├── /velocity ──► MotorController │ │ │ ├── pub /cmd_vel (geometry_msgs/Twist) │ │ │ ├── pub /state (std_msgs/Bool) │ │ │ └── pub /head_scalar │ │ │ │ │ └── /snapshot ◄── ROSCameraCapture │ │ └── sub /camera/color/image_raw │ │ │ │ Hexapod_Controller (C++) ◄── /cmd_vel, /state │ │ ros_astra_camera ──► /camera/color/image_raw │ └─────────────────────────────────────────────────────────────────┘

Get up and running

Quick Start

Five steps from clone to driving the robot.

1

Clone and create the venv

Requires Python 3.10+ on the laptop.

2

Install laptop dependencies

pip install -r requirements-laptop.txt

3

Deploy server to the robot

ROBOT_IP=x.x.x.x bash scripts/deploy_server.sh start

4

Drive with keyboard or PS5

python -m client.teleop --robot-ip x.x.x.x --controller ps5

5

Start line following

python -m client.line_follow --colour red --controller ps5

# 1. Clone
$ git clone https://github.com/MichaelAguadze/hexapodvla
$ cd hexapodvla
 
# 2. Install (laptop)
$ python3 -m venv venv && source venv/bin/activate
$ pip install -r requirements-laptop.txt
 
# 3. Deploy server to robot
$ ROBOT_IP=192.168.88.100 bash scripts/deploy_server.sh start
 
# 4. PS5 teleop
$ python -m client.teleop \
--robot-ip 192.168.88.100 --controller ps5
 
# 5. Line follow (red, PS5 override)
$ python -m client.line_follow \
--robot-ip 192.168.88.100 --colour red --controller ps5
